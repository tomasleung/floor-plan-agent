# RDLC AI Operating Model
## BI + AI Delivery Framework v1.0

Owner: Tomas Leung  
Purpose: Use AI agents to accelerate BI delivery while preserving governance, business intent, technical quality, and validation.

---

# 1. Purpose

RDLC exists to help organizations build BI solutions with stronger governance, clearer requirements, better technical design, and measurable decision value.

The goal is not to let AI randomly create reports.

The goal is to use AI agents inside a governed BI delivery process.

---

# 2. Core Idea

Microsoft Copilot or development agents can help build faster.

But they need:

- clear business requirements
- correct decision context
- proper data model design
- ETL rules
- KPI definitions
- report UX standards
- QA validation
- adoption checks

RDLC provides that missing governance layer.
